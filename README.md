# UUE

UUE (Uuencode) — метод представления двоичных данных в текстовой форме, пригодной для передачи через средства, предназначенные только для передачи текстов (например, через e-mail).

Название происходит от расшифровки названия программ uuencode/uudecode: Unix-To-Unix encoding (decoding). 

UUE данные начинаются со строки `begin mode file`, где `mode` — Unix-права доступа к файлу в восьмеричной системе счисления (сейчас всегда пишем число 644), а `file` — имя исходного файла.

При кодировании из файла берутся данные по три байта (в случае, если осталось меньше 3 байт, недостающие заменяются нулями). 
24 бита, образующие эти три байта, делятся на четыре группы по 6 бит. 
Каждая шестибитная группа интерпретируется как число (от 0 до 2<sup>6</sup>−1=63), к которому добавляется 32. 
Получившееся число в диапазоне от 32 до 95 трактуется как код символа в ASCII таблице. 

Каждая группа из 60 символов (соответствует 45 байтам исходного файла) используется для создания отдельной строки.
В начале строки указывается количество закодированных символов в строке (во всех строках, кроме последней, это символ `M`, так как для `45 + 32 = 77`, а код 77 у символа `M`).
Каждая строка завершается символом перевода строки `\n`.

После окончания данных кодируемого файла помещается строка, содержащая единственный пробел (и перевод строки), и строка с текстом `end`.

Например, исходный файл `cart.txt`, содержащий сообщение `Cat` будет закодирован как:
```
begin 644 cat.txt
#0V%T

end
```

Пояснение

Исходные символы: `Cat`

Всего 3 байта, `3 + 32 = 35`, символ с кодом 35: `#`

ASCII коды (десятич.): `67 97 116`

ASCII (двоичн.): `01000011 01100001 01110100`

ASCII (группы по 6 бит): `010000 110110 000101 110100`

Новые десятичные значения: `16 54 5 52`

Сдвиг на +32: `48 86 37 84`

Символы UUE: `0 V % T`



Необходимо написать программу, которая выполняет UUE кодирование.

Имена входного и выходного файлов задаются в командной строке. 

Например, для кодирования файла `input.txt` и записи ответа в файл `output.uue`:
```
   ./uuencode input.txt output.uue
```

## Требования
Программа не должна использовать контейнеры STL (std::vector, std::string и т. д.).
